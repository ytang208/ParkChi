# ParkChi Privacy Policy — Draft

**Effective date:** Replace before publication

ParkChi is designed to help users remember parking-related information on their iPhone.

## Information stored by the app

ParkChi may store parking notes, a selected parking-sign photo, a saved parking coordinate, reminder dates, and vehicle-renewal notes. This information is stored locally on the user's device. This version of ParkChi does not create user accounts or transmit this information to a ParkChi server.

## Location

ParkChi requests location access only when the user chooses to save their current parking location. The coordinate is stored locally so the user can open it later in Apple Maps.

## Photos

ParkChi lets the user select a parking-sign photo. The selected image is copied into the app's local storage and is not uploaded by this version of the app.

## Notifications

ParkChi requests permission to send local notifications for parking, street, and renewal reminders. Notification scheduling occurs on the user's device.

## Advertising and analytics

This version does not contain an advertising or third-party analytics service. This policy must be updated before either is added.

## Data deletion

Users can clear a saved parking spot and delete reminder entries inside the app. Deleting the app removes its locally stored data from the device, subject to the device's backup settings.
